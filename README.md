# games-for-websie

This repo now contains six self-contained browser game files:

- maze-runner.html
- arena-drift.html
- cave-hopper.html
- garden-defense.html
- factory-freight.html
- shipyard-scramble.html

Each file includes its own menu, gameplay loop, and localStorage save data, so you can drop the ones you want into an existing site or link them directly.

For a quick embed example, see [embed-snippets.md](embed-snippets.md).

Embeddable JS modules are available in `embeds/` if you want to mount games into an existing page element instead of using `iframe`.
